# Reclaim Proof Verification on XRPL

This project is a React application that integrates with the Reclaim Protocol and XRPL (XRP Ledger) to verify a proof and submit a transaction attesting to that proof on-chain. The application guides users through the process of generating a proof, verifying it, and recording the verification on the XRPL.

## Overview

This project demonstrates how to:

1. Create a claim using the Reclaim Protocol.
2. Verify the proof data generated by the claim.
3. Submit an XRPL transaction with the verified proof details as a memo.

The application starts by initializing a Reclaim Proof Request. Once the user completes the proof request, it verifies the proof and submits it to the XRPL with the transaction details.

## Features

- Create and initiate Reclaim proof request.
- Verification of proof via multiple steps, including witness signature validation.
- Submit a transaction to XRPL with the verified proof identifier as a memo.

## How to Use

1. **Clone the repository**
   ```sh
   git clone https://gitlab.reclaimprotocol.org/starterpacks/reclaim-xrpl-example.git
   cd reclaim-xrpl-example
   ```
2. **Install dependencies**
   ```sh
   npm install
   ```
3. **Configure Environment Variables**

   - Create a `.env` file in the root of the project.
   - Add your XRPL wallet secret key (only use testnet credentials in development):
     ```
     VITE_WALLET_SECRET=YOUR_WALLET_SECRET
     ```
     > [!TIP]
     > You can get a Funded wallet on Testnet from [XRP Faucet](https://xrpl.org/resources/dev-tools/xrp-faucets)

4. **Code Configuration**

   In `src/App.jsx`, fill in the necessary Reclaim credentials and replace `TODO` comments with your application-specific data:

   ```javascript
   const APP_ID = "YOUR_APP_ID"; // Replace with your application ID
   const PROVIDER_ID = "YOUR_PROVIDER_ID"; // Replace with your provider ID
   const APP_SECRET = "YOUR_APP_SECRET"; // Replace with your app secret
   ```

5. **Run the application**
   ```sh
   npm run dev
   ```
6. **Access the application**

   - Open your browser and navigate to `http://localhost:5173` (or the URL provided by Vite).

7. **Verify Proof**
   - Click on the "Create Claim" button to initiate the proof process.
   - Follow the QR code instructions to complete the proof.
   - After successful verification, the proof identifier will be recorded on the XRPL.
   - After the transaction is completed you can see it on the Explorer.

## Code Walkthrough

### App.jsx

The `App.jsx` file is the main component of the application. It manages the proof request lifecycle and handles UI interactions.

- **Proof Request Initialization**: When the component mounts, it initializes a Reclaim proof request using provided App ID, App Secret, and Provider ID.
- **Creating a Claim**: The `handleCreateClaim` function starts the proof request process and generates a QR code to be scanned by the user.
- **Proof Verification**: When the proof is received successfully (`onSuccess` callback), it calls the `verifyProof` function from `utils/verifyProof.js` to validate it.
- **Submitting the Transaction**: If the proof is verified successfully, the `submitTransaction` function from `utils/submitTransaction.js` is called to submit the proof identifier as a memo to the XRPL.

### utils/verifyProof.js

This utility script handles the proof verification process to ensure data integrity and authenticity.

- **Claim Data Hashing**: The function `createClaimInfoData` structures the claim information, and `keccak256` is used to hash this data.
- **Signature Validation**: The `recoverSignersOfSignedClaim` function extracts and verifies the signatures from the proof data, ensuring that no signatures are duplicated and all expected witnesses are valid.
- **Verification Logic**: The `verifyProof` function orchestrates the verification by performing multiple checks and throws an error if verification fails at any step.

### utils/submitTransaction.js

This utility script manages the interaction with the XRPL.

- **Connection to XRPL Testnet**: Uses `xrpl.js` to connect to the XRPL testnet to submit transactions.
- **AccountSet Transaction**: Prepares an `AccountSet` transaction containing a memo with the proof identifier in hexadecimal format. This memo serves as proof of verification on the XRPL.
